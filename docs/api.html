Plugin nedir, nasıl çalışır

Plugin, Bunker sunucularına eklenen küçük bir programdır: komutlara cevap verir, olayları dinler (mesaj, ses kanalı, üye), veri saklar, ses kanalında müzik/radyo çalar, panelde kendi penceresini gösterir.

  sen ── kodu yüklersin ──▶  Bunker (kısıtlı ortam)  ──▶  plugin'i eklediğin sunucular
                                     │
                                     └─ sadece SDK'nın verdiği işlemler (izin verdiklerin)
  • Kod Bunker'da, her plugin için ayrı ve kısıtlı bir ortamda çalışır. İnternete ve dosyalara erişemez; dışarıyla tek bağlantısı SDK'dır.
  • Plugin sadece eklendiği sunucularda çalışır ve sadece o sunucuların olaylarını görür. Özel mesajları (DM) hiçbir zaman görmez.
  • Sunucu sahibi plugin'i eklerken istediği izinleri görür ve onaylar.
  • Yeni plugin doğrulanmamıştır: sadece senin yönettiğin sunuculara eklenebilir, kod yükler yüklemez çalışır. Herkese açmak için Bunker ekibine incelettirirsin (Store'da yayınlama).

İlk plugin: yaz, yükle, çalışsın

1. İki dosya yaz.

bunker-plugin.json

{
  "name": "Zar Botu",
  "version": "1.0.0",
  "description": "Zar atar: !zar 20",
  "sdk": "0.1",
  "permissions": ["events.messages", "chat.send"]
}

plugin.js

import { definePlugin } from "@bunker-community/plugin-sdk";

export default definePlugin({
  setup(ctx) {
    ctx.command("zar", async (c) => {
      const yüz = Math.max(2, Math.min(1000, Number(c.args) || 6));
      await c.reply(`${c.nick} attı: ${1 + Math.floor(Math.random() * yüz)} (d${yüz})`);
    });
  },
});

2. Tek dosyaya paketle. Hiç kütüphane kullanmıyorsan plugin.js zaten tek dosyadır, bu adımı atla. Kullanıyorsan (Node.js 22+):

npm install @bunker-community/plugin-sdk
npx esbuild plugin.js --bundle --format=esm --platform=neutral --external:@bunker-community/plugin-sdk --outfile=bundle.mjs

3. Bunker'da oluştur ve yükle.

  1. Ayarlar → Geliştirici → Yeni plugin: ad yaz, Oluştur. (Çıkan anahtarı sakla; sadece kendi bilgisayarından test için gerekir.)
  2. Plugin'in satırında Kod yükle: kod dosyasını ve bunker-plugin.json'u (pencere varsa .html'i de) birlikte seç.
  3. Bunker'da çalıştır. Satırda "Bağlı (Bunker'da çalışıyor)" yazar.

4. Sunucuna ekle. Kendi sunucunda Sunucu ayarları → Plugin'ler (ya da Plugin Store) → Ekle → izinleri onayla. Kanala !zar 20 yaz.

Kodu değiştirince yeniden paketle ve Yeni kod yükle: yeni kod hemen devreye girer.

Geliştirirken test: kendi bilgisayarından bağlanmak

Her değişiklikte yüklemek yerine kodu kendi bilgisayarında çalıştırıp Bunker'a bağlayabilirsin. Plugin aynı sunucularda, aynı izinlerle çalışır; sadece kod senin makinende koşar (internete de çıkabilir).

npm install @bunker-community/plugin-sdk

local.js (package.json'da "type": "module" olmalı)

import { connect } from "@bunker-community/plugin-sdk";
import plugin from "./plugin.js";

connect(plugin, { token: process.env.BUNKER_TOKEN });
BUNKER_TOKEN=<anahtar> node local.js
# PowerShell: $env:BUNKER_TOKEN="<anahtar>"; node local.js
  • Anahtar Ayarlar → Geliştirici'de plugin'i oluşturunca bir kez gösterilir; kaybedersen Anahtarı yenile. Koda yazma, kimseyle paylaşma.
  • connect, klasördeki bunker-plugin.json'u ve pencere sayfasını her bağlanışta Bunker'a gönderir.
  • Plugin Bunker'da çalışırken kendi bilgisayarından bağlanılamaz (kod 4004); önce satırdaki Durdur'a bas.
  • Kodun kapalıyken bot çevrimdışı görünür, komutlara cevap gelmez.

connect(plugin, seçenekler)

SeçenekAçıklama

Döner: { ready: Promise<void>, connected: boolean, close(): Promise<void> }. Koparsa kendiliğinden yeniden bağlanır (1 sn → 30 sn). Anahtar geçersiz, plugin kapatılmış, manifest geçersiz ya da plugin Bunker'da çalışıyorsa yeniden denemez ve ready hata verir. Bu yolda ses kanalına ham PCM gönderilemez (playPcm yok); playMedia ve playUrl var.

Yaşam döngüsü

export default definePlugin({
  async setup(ctx) {
    // Plugin başlayınca bir kez: komutları, dinleyicileri burada kur.
    ctx.onUnload(async () => {
      // Kapanırken: zamanlayıcıları durdur, gerekiyorsa durumu depoya yaz.
    });
  },
});
  • setup hata fırlatırsa plugin başlamaz (Ayarlar → Geliştirici'de sebebi görünür).
  • Plugin kapanınca (durdurma, yeni kod, Bunker'ın yeniden başlaması): dinleyiciler bırakılır, ses oturumları kapanır, onUnload çalışır. onUnload içinde depo hâlâ kullanılabilir; toplam en fazla 3 sn.
  • Hata bütçesi: dinleyicilerin 60 sn içinde 10 hata fırlatırsa plugin kendiliğinden durur. Hataları yakala.
  • Plugin durunca eski ctx ile yapılan her çağrı plugin kapalı hatası verir.

interface PluginMessage {
  id: string; ts: number; uid: string; nick: string;
  text: string;         // ham metin: bahsetme <@uid>, özel emoji <:ad:id>
  system: boolean;      // "… sabitledi" gibi sistem satırı
  bot: boolean;         // bot/plugin yazdı (kendi mesajların dahil: cevap döngüsüne girme)
  attachments: number;  // görsel/video sayısı
  replyTo?: string; edited?: number;
}

Olaylar Bunker işini bitirdikten sonra gelir; yavaş bir dinleyici Bunker'ı bekletmez.

Komutlar: ctx.command(ad, fn)

ctx.command("selam", (c) => c.reply(`Selam ${c.nick}!`));
  • Ad: harf, rakam, _, -; 1-32 karakter; ! yazılmaz; küçük harfe çevrilir.
  • Sadece metin kanallarında ve insan yazınca tetiklenir.
  • Bunker'ın kendi komutları (!play, !skip, !rank, !bug…) ve başka plugin'in aldığı ad alınamaz.
interface CommandCall {
  gid: string; chan: string; uid: string; nick: string;
  args: string;                        // komuttan sonraki metin
  m: PluginMessage;
  reply(metin: string): Promise<void>; // aynı kanala (chat.send izni gerekir)
}

const r = await ctx.chat.send(chanId, "Merhaba!"); // { id } | null

Sadece eklendiğin sunucuların metin kanallarına; botun adıyla ve BOT işaretiyle görünür. 10 sn'de en fazla 10 mesaj. Metin en fazla 1800 karakter (fazlası kesilir). Bahsetme: <@uid>.

Store'da yayınlama

Doğrulanmamış plugin sadece senin sunucularında çalışır ve Store'da sadece sana görünür ("Doğrulanmamış" etiketiyle). Herkesin ekleyebilmesi için:

  1. Plugin'i kendi sunucunda düzgün çalışır hale getir.
  2. Bunker ekibine haber ver (support@bunker.community): plugin'in adı ve kimliği (ext-…).
  3. Ekip kodu inceler. Onaylanırsa Store'da herkese görünür (doğrulandı).

İnceleme şunlara bakar: istenen izinler gerçekten gerekli mi, açıklama doğru mu, kullanıcıyı yanıltan / taciz eden / spam yapan davranış var mı, kod okunabilir mi (bilerek gizlenmiş kod reddedilir).

Store'a alındıktan sonra yüklediğin her yeni kod da incelenir; onaylanana kadar eski onaylı sürüm çalışmaya devam eder. Kötüye kullanılan plugin kapatılır.

Sık sorulanlar

Plugin'im cevap vermiyor. Ayarlar → Geliştirici'de satır "Bağlı" mı? Sunucu ayarları → Plugin'ler'de plugin ekli mi, "Yeni izin istiyor" uyarısı var mı? Komut adı doğru mu? Hata satırında sebep yazar.

Dış bir API'ye istek atmam lazım. Bunker'da çalışan kod internete çıkamaz. Kodu kendi bilgisayarında / sunucunda connect ile çalıştır (test bölümü); bu şekilde kalıcı da çalışabilir.

TypeScript kullanabilir miyim? Evet; paketlerken esbuild TypeScript'i de çevirir. Tipler pakette var (import type { PluginContext } from "@bunker-community/plugin-sdk").

Kullanıcı başına ayar nasıl saklarım? Anahtara sunucu ve kişi kimliğini koy: ctx.storage.set("ayar:" + gid + ":" + uid, …).

Anahtarımı kaybettim / sızdı. Ayarlar → Geliştirici → Anahtarı yenile; eskisi hemen geçersiz olur.

Ek A: Geçit protokolü (başka dillerde yazmak)

SDK Node.js içindir. Başka bir dilde (Python, Go…) kendi makinende çalışacak bir bot yazmak istersen geçide doğrudan bağlan: WebSocket wss://bunker.community/app/api/plugin/gateway, JSON metin mesajları, mesaj ≤320 KB, saniyede ~30 çağrı.

Tanıtma (ilk mesaj, 10 sn içinde) ve cevabı:

{ "op": "hello", "token": "ext-…", "sdk": "0.1.4", "manifest": { "name": "…", "version": "1.0.0", "sdk": "0.1", "permissions": [] }, "uiPage": "<!doctype html>…" }
{ "op": "ready", "v": 1, "sdk": "0.1.4", "manifest": { "…": "…" }, "guilds": [{ "gid": "…", "name": "…" }] }

Çağrı → sonuç:

{ "op": "call", "id": 7, "method": "chat.send", "args": ["<kanal>", "merhaba"] }
{ "op": "result", "id": 7, "ok": true, "value": { "id": "<mesaj>" } }

Komuta cevap: chat.send ile call.chan'a. Bağlantı koparsa abonelikler silinir; yeniden bağlanınca tekrar gönder.

Ek B: Sürümler

Manifest'teki sdk: "0.1" → 0.1.x ile çalışır. Alanlar eklenir, silinmez; kırıcı değişiklikte sürüm numarası artar.

SürümDeğişiklik
0.1.4Plugin'i Bunker'a yükleme (barındırma), kendi bilgisayarından bağlanma (connect)
0.1.3playMedia, prefetch, meta olayı, error olayında silent
0.1.2Ses (voice.speak) ve panel penceresi (ui)
0.1.1guild.install / guild.uninstall olayları
0.1.0Olaylar, komutlar, depo, mesaj

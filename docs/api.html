Hızlı başlangıç

Uzak plugin (kendi bilgisayarında)

  1. Bunker'da Ayarlar → Geliştirici → Yeni plugin: ad yaz, "Oluştur". Çıkan anahtarı kopyala (bir kez gösterilir; kaybedersen "Anahtarı yenile").
  2. Boş bir klasörde (Node.js 22+):
npm init -y
npm install @bunker-community/plugin-sdk

package.json'a "type": "module" ekle. Klasöre iki dosya:

bunker-plugin.json (id yazma, anahtardan gelir)

{
  "name": "Selam Botu",
  "version": "0.1.0",
  "description": "!selam yazana cevap verir.",
  "sdk": "0.1",
  "permissions": ["events.messages", "chat.send", "storage"]
}

index.js

import { connect, definePlugin } from "@bunker-community/plugin-sdk";

const plugin = definePlugin({
  setup(ctx) {
    ctx.command("selam", async (c) => {
      const n = ((await ctx.storage.get(`n:${c.uid}`)) ?? 0) + 1;
      await ctx.storage.set(`n:${c.uid}`, n);
      await c.reply(`Selam ${c.nick}! (${n}. kez)`);
    });
  },
});

connect(plugin, { token: process.env.BUNKER_TOKEN });
  1. Çalıştır: BUNKER_TOKEN=<anahtar> node index.js (PowerShell: $env:BUNKER_TOKEN="<anahtar>"; node index.js). "bağlandı" yazınca Ayarlar → Geliştirici'de plugin "Bağlı" görünür.
  2. Kendi sunucunda Sunucu ayarları → Plugin'ler (ya da Plugin Store) → Ekle → izinleri onayla. Kanalda !selam yaz.

TypeScript kullanıyorsan tipler pakette var (import type { PluginContext } from "@bunker-community/plugin-sdk").

connect(plugin, options):

Döner: { ready: Promise<void>, connected: boolean, close(): Promise<void> }. Bağlantı koparsa kendiliğinden yeniden bağlanır (1 sn → 30 sn arası bekleyerek), dinleyiciler ve komutlar yeniden kaydedilir. Anahtar geçersiz, plugin kapatılmış, manifest geçersiz ya da aynı anahtarla başka bağlantı açılmışsa yeniden denemez ve ready hata verir.

Her bağlanışta manifest ve pencere sayfası Bunker'a gönderilir; değiştiyse orada güncellenir. Yeni izin eklediysen, eklendiği sunucularda yeniden onaylanana kadar plugin o sunucularda çalışmaz.

Kod kapalıyken: bot üye listesinde çevrimdışı görünür, komutlara cevap gelmez, ses oturumları kapanır. Sürekli açık kalması için kodu bir sunucuda (VPS, Raspberry Pi…) pm2 ya da systemd ile çalıştır.

export default definePlugin({
  setup(ctx) {
    ctx.command("selam", async (c) => {
      const n = ((await ctx.storage.get<number>(`n:${c.uid}`)) ?? 0) + 1;

Sonra kökte npm install, kökteki package.json → typecheck betiğine klasörü ekle, npm run typecheck. Bunker'ı yeniden başlat → Yönetim paneli → Sistem → Plugin'ler → aç → sunucu ayarlarından ekle. Kod Bunker sürecinde çalıştığı için bu yol sadece Bunker ekibinin yazdığı / incelediği plugin'ler içindir.

Dosyalar TypeScript, derleme yok (Node 22 tipleri silip çalıştırır). Bu yüzden enum, namespace, parametre özellikleri (constructor(private x)) gibi tip silmeyle çalışmayan söz dizimi kullanma; import'larda .ts uzantısını yaz.

İzinler

Plugin sadece manifest'te yazdığı izinlerin gerektirdiği şeyleri yapabilir; izinsiz çağrı hata fırlatır. Sunucu sahibi plugin'i eklerken bu listeyi onaylar. Plugin güncellenip yeni izin isterse, o sunucuda yeniden onaylanana kadar çalışmaz. Gereksiz izin isteme.

ctx.ui (pencere) ve ctx.log izin gerektirmez.

Kapsam: plugin sadece ekli olduğu sunucuların olaylarını duyar ve sadece oralara yazar / oradaki ses kanallarına girer. Özel mesajlar (DM) plugin'lere hiç gönderilmez.

Yaşam döngüsü

export default definePlugin({
  async setup(ctx) {
    // Plugin açılınca bir kez. Dinleyicileri burada kur.
    ctx.onUnload(async () => {
      // Kapanırken: zamanlayıcıları durdur, gerekiyorsa durumu depoya yaz.
    });
  },
});
  • setup hata fırlatırsa plugin error durumuna geçer.
  • Plugin kapatılınca (yönetim paneli, sunucu yeniden başlarken, hata bütçesi aşılınca): bütün dinleyiciler bırakılır, ses oturumları kapanır, onUnload fonksiyonları çalışır. onUnload içinde depo hâlâ kullanılabilir. Sunucu kapanırken plugin'lere toplam en fazla 3 sn tanınır.
  • Kapandıktan sonra eski ctx ile yapılan her çağrı "plugin kapalı" hatası verir; setTimeout vb. kendin açtığın şeyleri onUnload'da temizle.
  • Plugin kodu değişince sunucunun yeniden başlatılması gerekir (modül önbelleği).
  • Hata bütçesi: dinleyicilerinden 60 sn içinde 10 hata çıkarsa plugin kendiliğinden kapanır.

interface PluginMessage {
  id: string; ts: number; uid: string; nick: string;
  text: string;          // ham metin: bahsetme <@uid>, özel emoji <:ad:id> biçiminde
  system: boolean;       // "... sabitledi" gibi sistem satırı
  bot: boolean;          // bot ya da plugin yazdı (kendi mesajların dahil: döngüye girme!)
  attachments: number;   // görsel/video sayısı
  replyTo?: string; edited?: number;
}

Olaylar çekirdek işini bitirdikten sonra (ertelenerek) gelir: dinleyicin yavaş olsa da Bunker beklemez, cevabın kullanıcının mesajından sonra görünür.

Komutlar

ctx.command("zar", async (c) => {
  const yüz = Number(c.args) || 6;
  await c.reply(`${c.nick} attı: ${1 + Math.floor(Math.random() * yüz)}`);
});
  • İzin: events.messages (cevap için ayrıca chat.send).
  • Ad: harf, rakam, _, -; 1-32 karakter; küçük harfe çevrilir; ! yazılmaz.
  • Sadece metin kanallarında, insan yazınca tetiklenir (botlar komut çalıştıramaz).
  • Bunker'ın kendi komutları (!play, !skip, !rank, !bug …) ve başka bir plugin'in aldığı ad alınamaz (setup hata verir).
interface CommandCall {
  gid: string; chan: string; uid: string; nick: string;
  args: string;                 // komuttan sonraki metin
  m: PluginMessage;
  reply(text: string): Promise<void>; // aynı kanala
}

Mesaj gönderme

const r = await ctx.chat.send(chanId, "Merhaba!"); // { id } | null
  • İzin chat.send. Sadece ekli olduğun sunucunun metin kanallarına.
  • Plugin'in adıyla (sunucuda verilmiş özel adla) ve BOT işaretiyle görünür.
  • 10 sn'de en fazla 10 mesaj; fazlası hata.
  • Metinde bahsetme <@uid> biçiminde yazılır.

Depo

await ctx.storage.set("ayar:" + gid, { dil: "tr" });
const a = await ctx.storage.get<{ dil: string }>("ayar:" + gid); // yoksa undefined
await ctx.storage.delete("ayar:" + gid);
const anahtarlar = await ctx.storage.keys("ayar:");
  • İzin storage. Plugin'e özel (başka plugin göremez), Bunker'ın veritabanında, yeniden başlatmada kalır.
  • Değer JSON'a çevrilebilir olmalı, ≤64 KB. Anahtar 1-200 karakter; plugin başına ≤10 000 anahtar.
  • Veri bütün sunucular için ortak tek depoda: sunucuya ait veriyi gid önekiyle tut, guild.uninstall'da sil.

Ses

İzin voice.speak. Her ses kanalında ayrı bir oturum (bot kanalda ayrı üye olarak görünür).

const s = await ctx.voice.join(cid);   // zaten oradaysa aynı oturum
s.setVolume(30);
s.on("started", () => ctx.log.info("çalıyor"));
s.on("ended", () => ctx.log.info("bitti"));
s.on("error", (why, { silent }) => { if (!silent) ctx.log.warn(why); });
s.on("leave", (why) => ctx.log.info("ayrıldı: " + why));
await s.playMedia("daft punk one more time");

ctx.voice.session(cid) açık oturumu verir (yoksa null).

Model: durum aşağı, işlem yukarı

plugin (sunucu)  ── ctx.ui.setState ──▶  panel  ── postMessage {bunker:"state"} ──▶  sayfa (iframe)
plugin (sunucu)  ◀── ctx.ui.onAction ──  panel  ◀── postMessage {bunker:"action"} ──  sayfa

Sayfa kendi başına hiçbir yere bağlanamaz; bütün iş plugin'de, sayfa sadece durumu çizer ve tıklamaları iletir.

Sunucu tarafı

ctx.ui.onAction(async (a) => {
  // a: { gid, cid?, uid, nick, name, data }
  if (a.name === "sayac.arttir") {
    const n = ((await ctx.storage.get<number>("n:" + a.gid)) ?? 0) + 1;
    await ctx.storage.set("n:" + a.gid, n);
    ctx.ui.setState({ gid: a.gid }, { n, son: a.nick });
  }
});
  • setState({ gid, cid? }, state, { live? }): o sunucudaki (scope voice ise o kanaldaki) herkese anında gider; bağlanan kullanıcılar da son durumu alır. JSON, ≤32 KB. live: true → sol alttaki ikon yanar (ör. çalarken). null → temizle. Durum bellekte tutulur, yeniden başlatmada silinir (gerekirse depoya yaz).
  • onAction: Bunker önce kontrol eder: kişi sunucunun üyesi mi, scope voice ise o kanalda mı. Kişi başı saniyede ≤10 işlem, data ≤4 KB. Yine de data'yı güvenilmez girdi say ve doğrula.
  • Sayfa ilk açıldığında durum yoksa state: null gelir; bir "hello" işlemi gönderip durumu yayınlamak iyi bir alışkanlık.

Sayfa tarafı (ui/index.html)

<!doctype html>
<meta charset="utf-8">
<style>
  :root { --bg:#1e1f22; --text:#dbdee1; --accent:#6c6cff; }
  body { margin:0; padding:16px; background:var(--bg); color:var(--text); font:14px system-ui; }
  button { background:var(--accent); color:#fff; border:0; border-radius:6px; padding:8px 12px; }
</style>
<p id="t">…</p>
<button id="b">Arttır</button>
<script>
  const act = (name, data) => parent.postMessage({ bunker: "action", name, data }, "*");
  addEventListener("message", (e) => {
    const m = e.data;
    if (e.source !== parent || m?.bunker !== "state") return;
    for (const [k, v] of Object.entries(m.ctx.theme)) if (typeof v === "string") document.documentElement.style.setProperty("--" + k, v);
    if (!m.state) return act("hello");
    document.getElementById("t").textContent = `Sayaç: ${m.state.n} (son: ${m.state.son})`;
  });
  document.getElementById("b").onclick = () => act("sayac.arttir");
  parent.postMessage({ bunker: "ready" }, "*");
</script>

Mesajlar:

YönMesaj
sayfa → panel{ bunker: "ready" } (hazırım, durumu yolla) · { bunker: "action", name, data? } · { bunker: "close" } (pencereyi kapat)

Sayfanın kuralları:

  • <iframe sandbox="allow-scripts"> içinde, ayrı kökende açılır: panelin çerezlerine, verisine, DOM'una erişemez.
  • CSP: ağ isteği yok (fetch, WebSocket, form yok); script ve stil satır içi ya da plugin klasöründen, yazı tipi data: ya da klasörden. Görseller https:, data: ya da klasörden yüklenebilir (ör. kapak resmi). Tek dosya önerilir (uzak plugin'de zorunlu).
  • Sayfa sadece ui.page'in bulunduğu klasörden sunulur (/plugin-ui/<id>/…).
  • Panelin çevirisi (İngilizce) sayfaya uygulanmaz; ctx içinde dil yok, şimdilik metinleri sen seç.
  • Tema renklerini ctx.theme'den al ki açık/koyu temada uyumlu görünsün.

Bunker'da çalıştırma (barındırma)

Kodunu sürekli açık bir makinede tutamıyorsan Bunker çalıştırabilir. Kod aynıdır; sadece tek dosyaya paketlenir ve Bunker ekibi inceler.

  1. Kodunu tek bir ESM dosyasına paketle. @bunker-community/plugin-sdk dışında hiçbir import kalmamalı:
npx esbuild index.js --bundle --format=esm --platform=neutral --external:@bunker-community/plugin-sdk --outfile=bundle.mjs

Dosya export default definePlugin({ … }) içermeli ve connect() çağırmamalı (bağlantıyı Bunker kurar). Aynı kodu hem kendi bilgisayarında hem Bunker'da çalıştırmak istersen connect'i ayrı bir dosyaya koy:

// plugin.js: Bunker'a yüklenen kısım
import { definePlugin } from "@bunker-community/plugin-sdk";
export default definePlugin({ setup(ctx) { /* … */ } });

// local.js: sadece kendi bilgisayarında
import { connect } from "@bunker-community/plugin-sdk";
import plugin from "./plugin.js";
connect(plugin, { token: process.env.BUNKER_TOKEN });
  1. Ayarlar → Geliştirici → plugin'in satırında Kod yükle: bundle.mjs + bunker-plugin.json (+ pencere varsa .html sayfası) dosyalarını birlikte seç. En fazla 1 MB.
  2. Site yöneticisi kodu inceler: Onaylandı ya da Reddedildi (sebebiyle) görürsün.
  3. Onaylanınca Bunker'da çalıştır'a bas. Satırda "Bunker'da çalışıyor" yazar. Kendi bilgisayarından aynı anahtarla bağlanmak artık reddedilir (kod 4004); Durdur deyince yine kendi bilgisayarından bağlanabilirsin.
  4. Yeni kod yüklersen, onaylanana kadar eski onaylı sürüm çalışmaya devam eder.

Barındırılan kodun kuralları (kısıtlı süreç):

AğYok: fetch, WebSocket, http, net, dns… kapalı. Dışarıyla tek bağlantı Bunker API'si.
DosyaSadece kendi dosyası okunur; yazma yok. fs, os, child_process, worker_threads, vm kapalı.
OrtamOrtam değişkenleri boş; Bunker'ın anahtarları, veritabanı ve dosyaları görünmez.
Bellek128 MB (aşarsa süreç kapanır ve yeniden açılır).
İşlemci1 dk ortalaması %60'ı geçerse kapanır; 20 sn cevap vermezse (sonsuz döngü) kapanır.
ÇökmeYeniden açılır (2 sn → 60 sn bekleyerek); 10 dk'da 5 kez çökerse durur, satırda sebebi görünür.
Kayıtconsole.log / console.error Bunker kayıtlarına düşer (dakikada en fazla 60 satır).
DepoAynı depo: kendi bilgisayarındayken yazdıkların barındırılınca da durur.

Ağ gerektiren bir plugin (dış API çağıran hava durumu botu gibi) barındırılamaz; onu kendi makinende çalıştır.

Sürümler ve uyumluluk

  • SDK sürümü SDK_VERSION (şu an 0.1.4). Manifest'teki sdk alanı:
    • 0.x döneminde ara sürüm de kırıcı sayılır: "0.1" → 0.1.x ile çalışır, 0.2 ile çalışmaz.
    • 1.0 sonrası: "1" ya da "1.2" → aynı ana sürümde, en az o ara sürüm.
  • Kural: alanlar eklenir, silinmez / yeniden adlandırılmaz. Kırıcı değişiklik ana sürümü artırır.
  • Değişiklikler: 0.1.0 olaylar, komutlar, depo, mesaj · 0.1.1 guild.install/uninstall · 0.1.2 ses (voice.speak, playPcm/playUrl) + pencere (ui) · 0.1.3 playMedia, prefetch, meta, error.silent · 0.1.4 uzak plugin (connect), barındırma.

Yayınlama ve sunucuya ekleme

Uzak plugin:

  1. Ayarlar → Geliştirici'de oluştur (kişi başı en fazla 5), kodunu çalıştır.
  2. Doğrulanmamışken sadece senin sunucu ayarları yetkin olan sunuculara eklenebilir. Store'da sadece sana görünür ("Doğrulanmamış" etiketiyle).
  3. Herkese açmak için Bunker ekibine haber ver: site yöneticisi inceleyip yönetim panelinden "Sunucu sahipleri ekleyebilsin" derse Store'da herkese görünür (doğrulandı).
  4. Site yöneticisi kötüye kullanılan plugin'i kapatabilir; o zaman bağlantı kapanır (kod 4003).
  5. "Sil": plugin bütün sunuculardan çıkar, deposu silinir.

Bunker içinde (birinci taraf):

  1. Plugin plugins/<id>/ olarak repoya eklenir, incelenir, deploy edilir, Bunker yeniden başlatılır.
  2. Site yöneticisi (Yönetim paneli → Sistem → Plugin'ler): plugin'i açar (yüklensin) ve isterse "Sunucu sahipleri ekleyebilsin" der (Store'da listelenir). Yeni plugin kapalı ve listesiz gelir.
  3. Sunucu sahibi / server.manage yetkisi olan: Plugin Store'dan ya da Sunucu ayarları → Plugin'ler'den ekler, izinleri onaylar. Bot üye listesinde "Botlar" grubunda görünür, adı sunucuya özel değiştirilebilir.
  4. Kayıtlar: Yönetim paneli → Kayıtlar, etiket plugin.

Test ipuçları (yerel): PLUGINS_DIR ile başka plugin klasörü, PLUGIN_VOICE_WORKER ile sahte ses süreci, PLUGIN_MEDIA_FAKE=<sn> ile sahte medya (yt-dlp ve LiveKit gerekmez).

Geçit protokolü (SDK'sız bağlanmak)

SDK Node.js içindir. Başka bir dilde yazmak istersen geçide doğrudan bağlanabilirsin: JSON metin mesajları, WebSocket wss://bunker.community/app/api/plugin/gateway. Mesaj ≤320 KB, saniyede ~30 çağrı (anlık 60).

1. Tanıtma (ilk mesaj, 10 sn içinde):

{ "op": "hello", "token": "ext-…", "sdk": "0.1.4", "manifest": { "…": "…" }, "uiPage": "<!doctype html>…" }

manifest ve uiPage isteğe bağlı. Cevap:

{ "op": "ready", "v": 1, "sdk": "0.1.4", "manifest": { "…": "…" }, "guilds": [{ "gid": "…", "name": "…" }] }

2. Çağrı → sonuç:

{ "op": "call", "id": 7, "method": "chat.send", "args": ["<kanal>", "merhaba"] }
{ "op": "result", "id": 7, "ok": true, "value": { "id": "<mesaj>" } }
{ "op": "result", "id": 7, "ok": false, "error": "Bu kanala yazamazsın (plugin bu sunucuya ekli değil)." }
methodargsvalue
subscribe / unsubscribe[olay] (olay adları + "ui.action")—
command / uncommand[ad]—
chat.send[kanal, metin]{ id } ya da null
storage.get[anahtar]değer ya da null
storage.set[anahtar, değer]—
storage.delete[anahtar]—
storage.keys[önek]string[]
ui.setState[{ gid, cid? }, durum, { live? }]—
voice.join / voice.session[cid]oturum durumu (session: yoksa null)
voice.call[cid, işlem, argümanlar[]]; işlem: playUrl playMedia prefetch stop pause resume setVolume leaveoturum durumu

guilds[][{ gid, name }]

Oturum durumu: { gid, cid, playing, paused, volume, connected }.

3. Sunucudan gelenler:

{ "op": "event", "name": "member.join", "data": { "gid": "…", "uid": "…" } }
{ "op": "event", "name": "ui.action", "data": { "gid": "…", "cid": "…", "uid": "…", "nick": "…", "name": "…", "data": null } }
{ "op": "command", "name": "zar", "call": { "gid": "…", "chan": "…", "uid": "…", "nick": "…", "args": "20", "m": { "…": "…" } } }
{ "op": "voice", "cid": "…", "ev": "started", "args": [], "state": { "…": "…" } }

voice.ev: started, ended, error, meta, leave. Komuta cevap vermek için chat.send ile call.chan'a yaz.

Kapanış kodları: 4001 anahtar geçersiz / yenilendi · 4002 bozuk mesaj · 4003 plugin kapalı ya da silindi · 4004 aynı anahtarla yeni bağlantı açıldı (ya da plugin Bunker'da barındırılıyor) · 4005 manifest geçersiz (sebep reason'da) · 4008 çok hızlı ya da mesajları okumuyor. Diğer kopmalarda yeniden bağlan. Bağlantı koptuğunda abonelikler ve komutlar silinir; yeniden bağlanınca tekrar gönder.

Örnekler

  • plugins/hello: komut, olay, depo, mesaj.
  • plugins/radio: ses (playUrl) + pencere.
  • plugins/music: kanal başına sıra, playMedia + prefetch, pencere, yeniden başlatmada kaldığı yerden devam (onUnload + depo).
